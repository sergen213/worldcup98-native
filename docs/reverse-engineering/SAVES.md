# Save, Replay, and Presentation Data (WC98)

Status: **string-level evidence CONFIRMED** in `FIFAWC.EXE` (offsets
from `analysis/strings/FIFAWC.EXE.str.txt`); byte-level layouts are
**FIFA 99-derived hypotheses** pending Ghidra (project `wc98`, dumps to
`analysis/ghidra_*_dump.txt`) and real WC98 saves generated by running
the original game under Wine (research-only use of the Windows exe).

## options.sav — CONFIRMED present, layout HYPOTHESIS (FIFA 99 shared)

- Exe strings: `.\user\options.sav` (0x162780); `AFIF` magic strings at
  0x6A291, 0x6A754, 0x6A79E, 0x6A79E-adjacent Watcom literal pools.
- FIFA 99's `options.sav` is a 57-byte `AFIFAFIF` block with **fields
  fully mapped** (fifa99-native `docs/formats/OPTIONS_SAV.md`,
  parser `gameplay/src/options.cpp`; functions `Options_load/save`
  0x43B0E8/0x43B43C there). WC98 hypothesis: same 0x39-byte layout with
  WC98-specific fields (language enum for the 5 install languages,
  Classics-unlock state, 40-team selections).
- Verification plan: Ghidra xrefs to `AFIF` string + `.\user\options.sav`
  → loader function; compare copied ranges to FIFA 99's
  (+0A..+14, +23, +25, +26, +2C, +2D). Diff real WC98 saves produced
  by the original game (Wine, `-no3dx` software mode for reliability).
- The `options.sav` currently in the user's tree is an ASCII placeholder,
  not a game save — no genuine WC98 save exists on this machine yet.

## Competition saves, replays — container layout CONFIRMED (Ghidra pass 8)

- Saved competitions/replays: FIFA 99 uses `user\game%04.4d.sav` and
  `user\replay%02.2d.sav`. WC98 exe adds its own replay container:
  `user\rplyindx.dat` (0x1604A4) + `user\rply%04d.dat` (0x1604B8),
  with `FEREPLAYBUFF` (0x1604D4) and `replayfile` (0x1604E4) symbols.
- **CONFIRMED byte layout** (`analysis/pass8/rply_*.txt`, codec
  `formats/src/rply.cpp`, docs/asset-formats/RPLY.md): `.dat` = u32 record
  count + 142-dword state table (writer `FUN_00495e60`, loop bound 0x8e in
  `FUN_00495d10`) + size-prefixed record stream at file offset 0x23c
  (records = BE16 self-size prefix, walk `FUN_00496110`/`FUN_004963b0` over
  the FEREPLAYBUFF chain globals DAT_0057f83c/0x63699c/0x636994).
  `rplyindx.dat` = fixed 100 × 25-byte table (browser `FUN_0043c4f0`: slot
  number byte at entry+4, name string at entry+5). Input-stream replay model
  confirmed by structure; the exe's own per-record payload encoding needs a
  real Wine-generated file to enumerate (Wine replay generation blocked —
  wined3d GPU AV), so the native port gates on writer round-trip + constants.

## Network / modem user files — CONFIRMED strings

- `user\network.dat` (0x47859): LAN session settings (FIFA 99 sibling:
  `mltset.dat`/`mltdir.dat` with "Machine Name"/"Game Name" strings;
  WC98 equivalent strings GAMELIST/MACHINE/FIFAPW service confirmed in
  exe RE). `user\dial.dat` (0x161030): modem dial directory (TAPI play
  confirmed in `docs/reverse-engineering/EXECUTABLE.md` §2).

## Team history / tournament presentation — CONFIRMED loader pattern

- `fe\teamhist.<lang>\{du,en,fr,ge,it,da,sp,sw}.his` (0x89290-0x8933F)
  and `.tri` (0x8B3B0-0x8B451): per-language **team-history (Classic
  matches presentation: Wolstenholme-era clips, B&W flags) and
  tournament** data files; 8 language variants shipped (the multi-lang
  ISO exposes DA/SW/GE... beyond the 5 UI languages — commentary/data
  locales). Files exist in the tree (`.HIS` x8, `.TRI` x8, inventory
  §4). RE next: magic + record layout of `.his`/`.tri` (likely
  `FE_PACK`-embedded screens + text indexes into FCDB/FCLG).

## User customisation files (FIFA 99 family, expect in WC99 lineage)

- FIFA 99: `user\custom.db`, `cusplyr.db`, `tmmng.db`, `xfer.db`
  (custom teams, player edits, tactics, transfers). WC98 equivalents
  not yet string-located — grep pass pending in `analysis/strings`.
  FCDB `.DBM` (FCDBP*.DBM per language) is the shipped counterpart of
  `custom.db` in FIFA 99; WC98 schema delta = team record 68 B/17 words
  (see `docs/asset-formats/REUSABILITY.md` §5).
