# TMMNG_FORMAT_NOTES — Team Management tactics DB on WC98

## Status: file absent from the CD; engine support present

`WorldCup98_Extracted/USER/` contains only `options.sav` — no `tmmng.db`, `custom.db`,
`cusplyr.db`, `xfer.db`. The PC engine nevertheless registers all four user DB names:

* String cluster raw 0x164521..0x164544: `xfer.db`, `tmmng.db`, `custom.db`, `cusplyr.db`
  (VAs 0x564524/0x56452c/0x564538/0x564544, image base 0x400000).
* Path template `user\%s` raw 0x1645a8 — every user file opens as `USER\<name>`.
* Registration sites: `mov edx, imm32` (filename VA) + `call 0x4a50a0` path-template
  registrar @ 0x46df95 (xfer.db), **0x46dfba (tmmng.db)**, 0x46dfde (custom.db),
  0x46e002 (cusplyr.db) — the same registrar serves the `common\fcdb.dbi`,
  `common\fcdb_%s.dbi`, `common\fcdbpeng.dbi` CD paths @ 0x46e026..0x46e0b6.

Conclusion: `USER\tmmng.db` is created/updated at runtime when Team Management saves
(FE 'Management' save buttons; IGTEAM/IGOPTION pages). It is generated by the user, never
shipped; defaults come from the FCDB team record + formation module
(`TEAM_AND_FORMATION_REFERENCE.md`).

## Editor grammar (fifa98edit `read_tmmng`/`write_tmmng`, RTWC98 — reference only)

Per-team tactics block: 17 slot entries (slot used flag + positioning pair), attacking and
defensive positioning bytes, corner (left/right), free-kick, penalty and knockout-penalty
taker assignments. Coordinate space is the engine pitch grid [-128,128] (`sim::pitch`
convention), mirrored per side.

## What is verifiable on WC98

1. The runtime system the saved file feeds is the ported formation module:
   `Team_initPlayers 0x451210` tactics block (team +0x0C..+0x183), three formation records
   `+0x16 + i*0x6E` {mentality, slot entries u8 used, i8 dx, i8 dz, u16 tag}
   (`simulation/src/squad.cpp slotRec`), set-piece taker preference tables 0x586AEC/0x586B30
   consumed by `takerByOrder 0x4A0F3C`, base-slot lookup `0x4A0888`.
2. Byte-exactness of the saved layout is **unverified** for WC98: the file cannot be
   generated from the CD alone, and the original Windows release cannot reach Team
   Management under Wine (DirectDraw capture proven dead, `WINE_ORACLE_WC98.md`).
   Do not assume the RTWC 17×2-byte layout equals the WC98 layout.
3. Nothing in the repo reads or writes `tmmng.db`. Re-verification path (if a user ever
   generates the file on original Windows): compare slot entries against the `slotRec`
   record layout and the `kSlotFill` role masks (exe 0x586B74).

## Consequence for acceptance criteria

Original formations/positioning on WC98 come from the FCDB (tactics byte, role byte,
`GEN4TBLS.VIV` G98*.FMT coordinate tables) — recovered and integrated. The user-editable
tactics file exists as an engine concept with no shipped content to recover; recorded as a
documented gap, not a fabricated assumption.
